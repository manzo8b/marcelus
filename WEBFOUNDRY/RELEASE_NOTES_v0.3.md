# WebFoundry v0.3 — Technical showcase

**Status:** public source and repeatable demonstration; not a paid product, certified accessible website generator or hosted AI service.

## Functions

- Generates five pages per project for five sectors from one strictly validated MANZO AI Studio JSON blueprint.
- Produces HTML/CSS/JavaScript, sitemap-like manifest and reproducible structural-audit results.
- Preserves human review and `noindex` for generated demo content.
- Maintains a deterministic optional-skill router with provenance-bound advisory plans.
- Supports the earlier single-page creator as a separate backward-compatible command.

## Verification history

- Existing WebFoundry v0.3 test suite: **40 / 40 passed** during preparation in the local project environment.
- Project demonstrations: **5 sectors × 5 pages = 25 HTML pages**; earlier local audit reported all configured static checks passed.
- Browser and WCAG evidence: prior in-memory Chromium tests are not a substitute for full real-device/HTTP tests. Do not infer Lighthouse grades, screen-reader results or production security.
